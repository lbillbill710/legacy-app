# Legacy Product Requirements Document (PRD)

## Version
0.1.0

## Goal

Help fathers become more intentional every day through meaningful actions, reflection, teaching, and memory preservation.

## Success Criteria

A father should be able to:

- Create his profile
- Complete a daily mission
- Record a reflection
- Save a memory
- Create one teaching lesson

## Screens

- Welcome
- Profile Setup
- Home Dashboard
- Daily Mission
- Father Forge
- Teaching Room
- Legacy Archive

## Not Included

- Social media
- Messaging
- AI
- Subscriptions
- Play dates

These will come after Version 1.
