# Legacy Setup Guide

## Purpose

This guide explains how to take the Legacy project from GitHub files into a working Flutter application.

---

# Phase 1: Computer Setup

## Install Required Tools

Install:

- Flutter SDK
- Android Studio
- VS Code (recommended)

---

# Phase 2: Connect Legacy Repository

## Clone Repository

Download the Legacy project from GitHub onto the computer.

Repository:

legacy-app

---

# Phase 3: Create Flutter Project

Create the Flutter project structure.

Verify:

- lib folder exists
- main.dart is connected
- screens folder exists
- models folder exists
- data folder exists

---

# Phase 4: Add Legacy Code

Move existing files into the Flutter project:

## Screens

- welcome_screen.dart
- home_screen.dart
- profile_screen.dart
- mission_screen.dart
- weekly_review_screen.dart
- teaching_screen.dart
- archive_screen.dart

## Models

- mission.dart
- weekly_review.dart
- father.dart
- child.dart
- memory.dart
- legacy_lesson.dart
- legacy_archive.dart

## Data

- missions.dart

---

# Phase 5: Test Application

Run the app.

Check:

- App opens correctly
- Navigation works
- Screens display correctly
- No errors appear

---

# Phase 6: Future Development

Add:

- User accounts
- Cloud storage
- Photo/video storage
- Voice recordings
- Database
- Security features
- Notifications

---

# Phase 7: Play Store Preparation

Before publishing:

- Create app icon
- Create screenshots
- Write app description
- Create privacy policy
- Create Google Play Developer account
- Build release version
- Submit Legacy
